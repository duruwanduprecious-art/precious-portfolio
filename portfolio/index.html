Workflow

The Toolbox Trace

Every project starts with exploration, not cleaning: understanding the data before I touch it. From there, I clean, query and visualize, using AI to work faster along the way.

01

Explore First

Before cleaning anything, I profile the raw dataset, checking its structure, missing values, duplicates and early patterns, so every decision that follows is based on what's actually there, not assumptions.

02

Clean, Query, Verify

I clean what exploration reveals using Excel, Power Query and Python, then query it in SQL to answer the real business question, cross-checking anything surprising before I trust it.

03

Visualize & Work Smarter

I turn verified analysis into interactive dashboards in Power BI, Excel or Looker Studio, and use AI and automation throughout to speed up repetitive work without skipping the verification that makes the answer trustworthy.
